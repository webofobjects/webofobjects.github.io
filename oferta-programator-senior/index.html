Destinația ofertei

Prezenta ofertă este emisă în vederea utilizării în cadrul programului de finanțare europeană POCIDIF 2.1.

Obiectul ofertei

Furnizarea, în regim de tarifare orară, a serviciilor unui programator senior cu peste 6 ani de experiență profesională în dezvoltare software și expertiză într-un limbaj de programare utilizat curent în industrie.

Serviciile sunt prestate de un programator senior cu cunoștințe solide de algoritmi și structuri de date, arhitectură software și system design, precum și experiență în proiecte software complexe, versionarea codului și code review, testare și debugging, baze de date, integrarea API-urilor, securitatea și calitatea codului. Limba engleză: minimum B2 (CEFR), inclusiv pentru comunicare și documentație tehnică.

Alocarea programatorului pentru prestarea serviciilor este condiționată de acceptarea acestuia de către WEB SOCIETY SRL în urma unui interviu tehnic.
